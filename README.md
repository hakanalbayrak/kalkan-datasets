# Kalkan Datasets

Public, generated datasets for Kalkan caller identification and call blocking.

Published files:

- `exact_blocking_TR.json`
- `caller_id_TR.json`
- `general_protection_TR.json`

Primary public base URL:

`https://hakanalbayrak.github.io/kalkan-datasets`

Files are generated by the Kalkan backend and synchronized after successful admin publish. Do not edit generated dataset content manually.
